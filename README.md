# Shubhadip Banerjee — Portfolio

A high-performance personal portfolio website for **Shubhadip Banerjee** (B.Tech Computer Science & Engineering - AI student).

## ✨ Features
- **Modern Dark Aesthetic**: Deep `#07070a` palette with glowing red accent lines and glassmorphism.
- **Dynamic Roaming Cursors**: Collaborative Figma-style roaming cursors with role badges and subtle click interactions.
- **Wireframe Blueprint Intro**: Interactive section reveal animation showcasing structure and component dimensions.
- **Typing Hero & Holographic Scanner**: Live role typing effect with scanning photo frame.
- **Selected Works**: LensBox Android Gallery App (with interactive feature specs and animated stats), Car Accident Alert System, Gym Management System, and WebDev Evaluator.
- **Interactive Particle Constellation**: Real-time canvas particle network reacting to pointer movements in the Contact section.
- **Fully Responsive & Accessible**: Seamlessly adapts to desktop, tablet, and mobile with `prefers-reduced-motion` support.

## 🚀 Live Demo & Deployment
This website is ready for GitHub Pages:
1. Go to repository **Settings** → **Pages**.
2. Under **Build and deployment** > **Branch**, select `main` (or `master`) and `/ (root)`.
3. Click **Save**.
4. Your site will be published at:
   `https://777shubhadip-sudo.github.io/portfolio/`
