Featured project

LensBox — Android gallery app with two hidden folders

A gallery app with a glass-style interface, gradient backgrounds and consistent fonts for browsing and organizing photos in albums. It keeps private photos in a Hidden Folder and an extra secret folder that opens only with a separate pass you set.

How it's built — click to open
  • InterfaceGlass-style UI with gradient backgrounds and consistent fonts for browsing photos and albums
  • Private storageA Hidden Folder plus a second secret folder that opens only with its own user-set pass
  • SecurityBiometricPrompt (fingerprint or screen lock); the pass is stored only as a salted hash in EncryptedSharedPreferences
  • SettingsTheme (dark, light or system), grid density, trash retention and biometric re-lock timeout
